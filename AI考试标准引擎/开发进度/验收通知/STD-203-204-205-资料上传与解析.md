### 管理员 Token 怎么拿

标准引擎接口需要 **`role=admin`**。JWT 来自登录接口的 `access_token`（不是 License、也不是 BYOK）。

**1. 配置首个管理员（仅首次注册生效）**

在 `services/api/.env`（或仓库根 `.env`）设置：

```env
BOOTSTRAP_ADMIN_EMAIL=你的邮箱@example.com
```

**2. 注册或登录**

```bash
# 若该邮箱尚未注册（注册时邮箱与 BOOTSTRAP_ADMIN_EMAIL 一致 → 自动 admin）
curl -s -X POST http://127.0.0.1:8000/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"你的邮箱@example.com","password":"你的密码"}'

# 已注册则用登录
curl -s -X POST http://127.0.0.1:8000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"你的邮箱@example.com","password":"你的密码"}'
```

响应示例：`{"access_token":"eyJ...","token_type":"bearer"}` → 把 `access_token` 填到下面 `Bearer` 后面。

**3. 确认是管理员（可选）**

```bash
curl -s http://127.0.0.1:8000/auth/me \
  -H "Authorization: Bearer eyJ..."
```

应看到 `"role":"admin"`。若是 `"user"`，说明注册时未命中 `BOOTSTRAP_ADMIN_EMAIL`，需换邮箱重新注册或改库 `users.role`。

**Web 端**：浏览器登录后，DevTools → Network → 任意带鉴权请求 → Request Headers 里的 `Authorization: Bearer ...` 即为同一 Token。
