# 架构与模块说明（大作文 V1）

| 基线 | 产品需求 V1.2-E + 技术选型 V1.4 |
|------|----------------------------------|

## 1. 逻辑架构

```text
                    ┌─────────────────────────────────┐
                    │  apps/web (React + Ant Design)   │
                    │  首页 · 批改 · 报告 · 设置 · 激活  │
                    └───────────────┬─────────────────┘
                                    │ /api → FastAPI
                    ┌───────────────▼─────────────────┐
                    │  services/api                    │
                    │  auth │ license │ byok │ exam  │
                    │  questions(essay) │ submissions │
                    │  grading_jobs │ reports         │
                    └───────────────┬─────────────────┘
                                    │
              ┌─────────────────────┼─────────────────────┐
              ▼                     ▼                     ▼
         SQLite/PG            用户 BYOK              后台线程/Celery
         licenses…            chat/completions         run_grading_job
```

**批改主路径**：`POST /submissions` → `POST /submissions/{id}/grade` → `run_grading_job` → `Report` → 前端轮询 `GET /grading-jobs/{id}` → `GET /reports/{id}`。

## 2. 领域边界

- **唯一题型**：`QuestionType.essay`  
- **题目**：`prompt`（主）+ `material`（可选背景）+ `scoring_points`（维度 rubric）  
- **批改**：不对「材料要点」做摘抄式匹配；对**篇章与维度**评分  
- **商业**：`License` + `user_provider_credentials` 双门禁  

## 3. 目录约定

| 路径 | 职责 |
|------|------|
| `apps/web/src/pages/` | 页面；`GradingPage` / `HomePage` / `ReportPage` 为核心 |
| `apps/web/src/components/GradingJobPanel.tsx` | 大作文批改进度 |
| `services/api/app/domain/essay.py` | 大作文常量、标签、能力维、字数 |
| `services/api/app/services/grading_service.py` | 批改编排与 Prompt |
| `services/api/app/models/entities.py` | 持久化模型 |
| `方案调研/` | PRD 修订、技术选型 |
| `开发计划及进度/` | 计划、验收、本文档 |
