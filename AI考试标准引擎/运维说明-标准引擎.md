# AI 考试标准引擎 — 运维说明（STD-707）

## 数据库与 Alembic（DEC-05）

- **日常开发**：仍以 `python scripts/init_db.py`（`create_all` + 列补丁 + seed）为主。
- **Alembic**：`services/api/alembic/`，当前 **001_baseline** 为 stamp 基线（空 upgrade，不重复建表）。
- 新库或已跑过 init_db 的库：

```bash
cd services/api
python scripts/init_db.py
alembic stamp head
python scripts/verify_alembic.py
```

- 后续 schema 增量：新增 revision，`alembic upgrade head`（生产逐步切换；与 init_db 补丁并存期需人工对齐）。

## 依赖服务

- **API**：`uvicorn app.main:app`（`services/api`，使用 `.venv`）
- **可选 Celery**：标准任务经 `standards` 队列；批改经 `grading` 队列。无 Redis 时在 API 进程内同步执行

## 环境变量

| 变量 | 默认 | 说明 |
|------|------|------|
| `STANDARD_GEN_MODE` | `auto` | `stub` / `llm` / `auto` |
| `STANDARD_PUBLISH_MIN_CONFIDENCE` | `0.85` | 见 `settings.standard_publish_min_confidence` |
| `STANDARDS_UPLOAD_DIR` | `uploads/standards` | 上传资料目录 |
| `STANDARD_USE_P05` | `1` | `0` 关闭 LLM P05，仅用启发式覆盖度 |
| `STANDARD_GEN_CACHE` | `1` | `0` 关闭 LLM 流水线结果缓存（表 `standard_pipeline_cache`） |
| `STANDARD_DUAL_MODEL` | `0` | `1` 时用共识 BYOK 再跑 P03，Jaccard 写入准则 `model_agreement` |
| `STANDARD_AI_ANNOTATION` | `1` | `0` 关闭 validated 后自动反写 `questions_for_labeling.csv` |
| `STANDARD_AUTO_PUBLISH` | `0` | `1` validated 后自动 publish |
| `STANDARD_AUTO_PUBLISH_FORCE` | `0` | `1` 自动发布时忽略置信度门槛 |

## 故障排查

| 现象 | 处理 |
|------|------|
| job 一直 `pending` | 检查 worker 线程 / 手动 `--sync` 跑 pipeline |
| publish 400 置信度 | 调高质量或 `POST .../publish?force=true` |
| LLM 400 | Admin BYOK 测试连接；换支持 JSON 的模型 |
| multipart 错误 | `pip install python-multipart` |
