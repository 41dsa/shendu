# AI 考试标准引擎 — 运维说明（STD-707）

## 数据库与 Alembic（DEC-05）

- **日常开发**：仍以 `python scripts/init_db.py`（`create_all` + 列补丁 + seed）为主。
- **Alembic**：`services/api/alembic/`，当前 **001_baseline** 为 stamp 基线（空 upgrade，不重复建表）。
- 新库或已跑过 init_db 的库：

```bash
cd services/api
python scripts/init_db.py
alembic stamp head
python scripts/verify_alembic.py
```

- 后续 schema 增量：新增 revision，`alembic upgrade head`（生产逐步切换；与 init_db 补丁并存期需人工对齐）。

## 依赖服务

- **API**：`uvicorn app.main:app`（`services/api`，使用 `.venv`）
- **可选 Celery**：标准任务经 `standards` 队列；批改经 `grading` 队列。无 Redis 时在 API 进程内同步执行

## PRD V1 诊断教练（Trait 路径）

- **批改主路径**：`layered_scoring_engine_enabled=1`，`grading_point_pool_engine_allowed=0`（禁止回退采分点池）。
- **标准卡教研审核**：Admin → 考试标准引擎 →「标准卡教研审核」；API `POST /admin/standards/jobs/{id}/standard-card-review`（`publish_after: true` 可一次通过并发布）。
- **三模型标准共识**：设 `STANDARD_CONSENSUS_3MODEL_ENABLED=1` 后，流水线步骤 `standard_card_v1_consensus` 走 `standard_consensus_pipeline`；低共识或 `dispute_marks` 需 M-14 审核后再发布（勿长期依赖 `force=true`）。
- **自备四档阅卷**：`.env` 设 `CUSTOM_ESSAY_GRADING_MODE=traditional_marking`；Prompt 正文默认 `services/api/data/prompts/custom_traditional_grading.txt`，Admin → Prompt 版本 →「自备批改 · 四档阅卷主评」可改；占位符 `{{题目}}` `{{材料}}` `{{作答要求}}` `{{规定字数}}` `{{作文正文}}` `{{满分}}` 等由批改任务自动填充。
- **锚作文**：Admin → 锚作文；或 `POST /admin/anchor-essays/seed-demo?question_id=` / CLI `seed_demo_anchors.py`。
- **题目 ↔ 标准版本**：`GET /admin/questions` 含 `standard_link`；`GET /admin/questions/{id}/standard-link`。
- **EssayItem 导入（Q-03）**：`POST /admin/standards/questions/import-csv`（默认锁定 A 类字段）；`POST /admin/standards/questions/import-essay-items-json`；审计 `GET /admin/standards/essay-import-audits`。
- **合规门禁**：`python scripts/verify_prd_v1_compliance.py`（含 DEP 守卫、Trait 记录、锚对 Spearman 等）。
- **主动学习池**：Admin → 主动学习池；`GET /admin/active-learning/export.jsonl`。
- **锚 Trait 标注**：Admin → 锚 Trait 标注（`/admin/anchor-annotation`）。
- **三模型集成冒烟**：`python scripts/verify_standard_consensus_pipeline_integration.py`（mock 三路由）。
- **V2 弱监督/锚校准**：`GET /admin/weak-supervision/bundle`；`GET /admin/questions/{id}/anchor-calibration`。
- **V3 校准门禁**：`GET /admin/calibration/metrics`；CLI `python scripts/run_calibration_gate.py`（金标 QWK + 锚多评 ICC/QWK）。环境变量 `V3_CALIBRATION_MIN_QWK`（默认 0.55）、`V3_CALIBRATION_MIN_GOLD_RUNS`。

## 故障排查

| 现象 | 处理 |
|------|------|
| job 一直 `pending` | 检查 worker 线程 / 手动 `--sync` 跑 pipeline |
| publish 400 置信度 | 调高质量或 `POST .../publish?force=true` |
| LLM 400 | Admin BYOK 测试连接；换支持 JSON 的模型 |
| multipart 错误 | `pip install python-multipart` |
