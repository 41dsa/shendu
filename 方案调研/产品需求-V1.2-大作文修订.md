## 1. 产品一句话

AI申论教练，帮你把**每一篇大作文**写得更稳：知道为什么丢分，并能在**重写一遍**里看见改善。

---

## 2. V1 边界（大作文）

### 2.1 包含

- 注册登录、考试目标、首页、**大作文 AI 批改**（文本输入）  
- 维度化评分、规则预评、多模型共识（可分层）、置信度、失分诊断、修改建议  
- 批改报告、评分依据、（P5）二次作答与对比、能力画像、问题本、AI 训练  
- 教研后台最小闭环、金标、评分争议、埋点、BYOK 用量记录  

### 2.2 不包含（V1）

- 小题：归纳概括 / 综合分析 / 提出对策 / 贯彻执行  
- 应用文、OCR、Android、站内支付、平台统一 LLM Key、真人批改  

---

## 3. 信息架构（Web）

```text
智观申论 / AI申论教练
├── 首页          … 能力概览、重点问题、推荐大作文题、最近批改
├── 批改          … 选题、题干、参考背景、正文、进度、报告
├── 批改报告      … 列表 + 详情（维度、问题、建议、争议入口占位）
├── 购买/激活     … 爱发电 + 兑换码
├── 设置          … AI Key、考试目标
└── （P5+）训练 / 能力 / 问题本 / 我的
```

与 PRD §5 对齐，**「AI批改」子流程**改为：选题 → 输入**全文** → 提交 → 解析题干/字数 → 结构/立意/论证分析 → 规则预评 → 共识 → 报告。

## 4. 大作文评分对象

### 4.1 题目数据

| 字段 | 说明 |
|------|------|
| `title` | 列表短标题 |
| `question_type` | 固定 `essay` |
| `prompt` | 题干与作答要求（字数、是否自拟标题等） |
| `material` | 可选**参考背景**（非小题阅读） |
| `material_structured` | `word_min` / `word_max` / `exam` / `genre: essay` |
| `scoring_points` | **评分维度**（非材料采分点），默认四～五维 |

### 4.2 批改输出（对齐 PRD §7.3.5，语义映射）

| PRD 字段 | 大作文实现 |
|----------|------------|
| 总分 / 区间 / 置信度 / 共识一致率 | 已实现 |
| 采分点命中 | **各维度得分**（full/partial/miss） |
| 问题标签 | Q21～Q25、Q17、Q20 等 |
| 修改建议、二次作答要求 | 已实现（二次作答 P5） |
| 评分依据 | `GET /reports/{id}/basis` |
| 争议入口 | P6 |

### 4.3 批改进度步骤（对用户可见）

解析题干 → 核对字数与要求 → 分析篇章结构 → 分析立意与观点 → 分析论证与素材 → 规则预评 → AI 综合评分 → 共识复核 → 生成报告  

（代码：`grading_service.GRADING_STEPS` + `GradingJobPanel`）

### 4.4 短路规则（PRD §7.3.6）

- 空白、**字数严重不足**（低于 `word_min` 约 30%）、严重跑题（后续补关键词/模型判定）→ 低置信、「仅供参考」、不建议展示精确总分

## 6. 能力模型（V1 启用 5 维）

| 维度 ID | 名称 | 说明 |
|---------|------|------|
| A1 | 立意与审题 | 扣题、观点鲜明、价值导向 |
| A2 | 结构与层次 | 标题、开头、分论点、结尾 |
| A3 | 论证与素材 | 论据、分析深度、联系实际 |
| A4 | 语言表达 | 流畅、规范、修辞适度 |
| A5 | 规范与字数 | 字数区间、格式、卷面（文本 proxy） |

**计算（P5）**：近 N 次大作文批改的维度均分 + 问题标签权重 + 难度归一；置信度低时不展示趋势（PRD §7.13）。

---

## 7. 验收标准（大作文版，替代 PRD §21）

**单篇验收示例**（国考副省级类）：

- 输入：题干 + 可选参考背景 + 800～1200 字考生作文  
- 输出：总分（如 32/40）、区间、置信度、共识一致率、四维/五维得分、≥1 条 Q21～Q25 类问题、3～5 条建议  
- 二次作答（P5）：32 → 36，问题「论证不足」严重 → 已改善  

**里程碑**：

- **M1**：账号 + 买断 + BYOK + 大作文提交 + 基础报告  
- **M2**：共识 + 置信度 + 完整报告 + 缓存 + 依据 API  
- **M3（规划）**：二次作答 + 能力 + 问题本  
- **M4（规划）**：训练推荐 + 教研/金标/争议
