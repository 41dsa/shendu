## 1. 枚举与常量

### 1.1 资料来源等级 `SourceLevel`

| 值 | 含义 |
|----|------|
| `S` | 官方大纲、官方说明 |
| `A` | 权威教材 / 官方解析 |
| `B` | 公开参考答案、机构解析 |
| `C` | 论坛、自媒体（仅作参考，默认降权） |

### 1.2 标准状态 `StandardStatus`

`draft` | `in_review` | `published` | `archived`

### 1.3 能力维（与现网一致）

`A1` 立意与审题 · `A2` 结构与层次 · `A3` 论证与素材 · `A4` 语言表达 · `A5` 规范与字数

### 1.4 默认卷面维度 ID

`D01`～`D04`（可选 `D05` 规范与字数），见 `DEFAULT_RUBRIC_DIMENSIONS`。

## 7. RubricCriterion（M5，大作文「语义单元」）

对应小题文档的 `ScoringPoint`，但评价对象是 **篇章表现**。

```json
{
  "id": "RC001",
  "dimension_id": "D03",
  "ability_id": "A3",
  "core": "分论点有论据支撑且与分析句搭配",
  "observable_signals": [
    "各段有事实/政策/案例类论据",
    "论据后有过渡或分析句"
  ],
  "acceptable_expressions": [],
  "typical_gaps": ["堆砌例子无论证", "仅复述材料"],
  "counter_examples": ["纯口号无实例"],
  "issue_tags": ["Q24", "Q23"],
  "max_score": 2,
  "score_min": 1,
  "score_max": 2,
  "weight": 0.2,
  "confidence": 0.91,
  "usage_band": "high",
  "source_refs": [{"document_id": "uuid", "excerpt": "解析：论证…"}]
}
```

`usage_band`：`high`（≥0.85）/ `medium` / `low`（<0.70）；低置信准则不得单独作为强制扣分依据。

`scoring_rules.score_confidence_declaration`：`high` | `medium` | `low`，声明分值非官方尺度（默认 `medium`）。

批改报告可选 `evidence_chain[]`：准则 → 用户引文 → 材料依据 → 得分说明。

> 用户作文匹配时：「论据后缺少分析」→ 命中 `typical_gaps` 关联 `RC001`，**非**关键词匹配。

## 8. RubricStandard / ScoringStandard（M5 聚合）

```json
{
  "question_id": "uuid",
  "version": 3,
  "total_score": 40,
  "dimensions": [
    {
      "id": "D01",
      "label": "立意与观点",
      "max_score": 10,
      "ability": "A1",
      "required": true,
      "criteria": ["RC001", "RC002"]
    }
  ],
  "criteria": [ { "...": "RubricCriterion 对象数组" } ],
  "scoring_rules": {
    "partial_hit_policy": "维度内按准则加权；partial 给 50% 准则分",
    "short_circuit": {
      "word_count_below_ratio": 0.3,
      "action": "low_confidence_only"
    }
  },
  "loss_rules": [
    {
      "id": "LR01",
      "when": "thesis_off_topic",
      "dimension_id": "D01",
      "deduction_cap": 8,
      "issue_tag": "Q21",
      "explanation_template": "立意偏离题干核心…"
    }
  ]
}
```

**现网兼容**：发布时将 `dimensions` 映射为 `Question.scoring_points`：

```json
{"id": "D01", "label": "立意与观点", "max_score": 10, "required": true, "ability": "A1"}
```

完整 `criteria` / `loss_rules` 存 `exam_question_standards.payload` JSONB。

## 11. 持久化表草案（PostgreSQL）

| 表名 | 用途 |
|------|------|
| `standard_documents` | M1/M2 资料与解析文本 |
| `standard_generation_jobs` | Celery 任务与当前步骤 |
| `standard_job_steps` | 每步输入输出 JSON |
| `exam_question_standards` | question_id + version + status + payload（QuestionStandard + RubricStandard + ValidationResult） |
| `exam_standards` | 可选考试级 |

索引建议：`(question_id, status, is_active)` 唯一部分索引（仅一条 active published）。
