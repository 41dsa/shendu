## 验收步骤

```bash
cd services/api && source .venv/bin/activate
python scripts/seed_standard_essay_batch.py
```

任选一题 id（除 `demo-essay-001` 外的新题）：

```bash
curl -s http://127.0.0.1:8000/admin/standards/questions/<question_id>/structured \
  -H "Authorization: Bearer $TOKEN" | head -c 400
```

关联资料（可选）：

```bash
curl -X POST http://127.0.0.1:8000/admin/standards/questions/<question_id>/link-documents \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"document_ids":["<document_id>"]}'
```
